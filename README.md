# Smart Railway Crossing Control System (SRCCS)

## Overview
This project demonstrates formal verification of a railway crossing system using Z, VDM, and Alloy.

## Objective
Ensure that no train passes while the barrier is open.

## Files Included
- requirements.txt
- zModel.txt
- vdm.txt
- alloy.txt
- verification.txt

## Tools Used
- Z Tool
- Overture (VDM)
- Alloy Analyzer
